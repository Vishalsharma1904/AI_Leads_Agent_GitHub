India location catalogue for the Run Agent picker.

Source: [Countries States Cities Database](https://github.com/dr5hn/countries-states-cities-database), downloaded 2026-10-05 from the project's JSON exports. This extract contains 36 states/union territories and 4,198 distinct place names grouped by state. It is a community catalogue, not a guarantee of every locality. Custom locality entry remains available.

The India extract is distributed under ODbL-1.0. The full license is preserved in `india-locations.LICENSE`; source attribution is also shown in the picker. Names were filtered to India and deduplicated within each state; no coordinates or user location data are included.
