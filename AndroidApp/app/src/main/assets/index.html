💡 Google Script Setup Guide

1 Naya Project Banayein:
Google Apps Script (script.google.com) par jayein. "New Project" banayein aur usme email_script_gas.js ka code paste karein.
2 Web App Deploy Karein:
Top-right me Deploy > New Deployment click karein. Settings (Gear icon) me Web App chunein. (Execute as: "Me", Access: "Anyone").
⚠️ Warning Bypass: Deploy par click karne par "Authorize Access" dabayein, account select karein, fir Advanced > Go to project (unsafe) chunein aur Allow kar dein.
3 URL Paste Karein:
Milne wale Web App URL ko copy karein aur left box me daal kar **Connect** dabayein (ya config.js file me update kar dein).
*Note: Ye steps sirf pehli baar (first deployment) par karne hote hain. Iske baad app automatic backend me secure email sending perform karegi.
